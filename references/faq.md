# ❓ 积极育儿 — 常见问题与应对

## 场景索引

### 发脾气 / 情绪崩溃
- **理解：** 孩子的大脑还在发育，无法很好地处理强烈情绪
- **应对：** 先连接再纠正 → 共情 → 积极暂停 → 事后讨论
- **避免：** 说教、威胁、以暴制暴

### 不合作 / 顶嘴
- **理解：** 可能是寻求权力或寻求关注
- **应对：** 不应战、给有限选择、家庭会议上讨论
- **避免：** 权力之争、强制服从

### 打人 / 攻击行为
- **理解：** 孩子可能还没有学会用语言表达愤怒
- **应对：** 保护所有人安全 → 共情 → 教替代方式
- **避免：** 以打还打

### 不愿做家务 / 拖延
- **理解：** 可能是任务太难或缺乏动力
- **应对：** 花时间训练、一起做、日常惯例表
- **避免：** 唠叨、代做、惩罚

### 兄弟姐妹冲突
- **理解：** 竞争归属感和父母关注
- **应对：** 不当裁判、分别特殊时光、家庭会议解决
- **避免：** 比较、偏袒

### 说谎
- **理解：** 害怕惩罚或想让大人高兴
- **应对：** 创造安全的环境、关注解决问题而非追责
- **避免：** 严厉质问、惩罚

### 公共场合失控行为
- **理解：** 过度刺激、缺乏自控
- **应对：** 预防为主（提前约定）、带离现场、保持冷静
- **避免：** 当众羞辱、威胁

### 不肯睡觉
- **理解：** 分离焦虑、怕错过、缺乏惯例
- **应对：** 建立睡前仪式、给予选择、特殊时光
- **避免：** 强迫、用睡觉作为惩罚

## 对大人的提醒
1. 先控制自己的情绪
2. 孩子的行为不是针对你
3. 错误是学习的好机会
4. 温和而坚定
5. 明天又是新的一天
