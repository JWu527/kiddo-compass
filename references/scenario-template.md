# Scenario Template Library

Use this file to keep scenario advice consistent. Every scenario card should have four layers:

1. Quick help: what to say/do now.
2. Why it may be happening: short, non-shaming explanation.
3. Prevention: what to set up before next time.
4. If it does not work: next step or escalation threshold.

## Card template

```text
Scene:
Age band:
Caregiver:
Risk check:
Quick help:
Script:
Prevention:
If it fails:
Load:
```

## Eight public-beta scenario skeletons

### Bedtime delay

- Quick help: make the final limit visible before the last story.
- Script: "今晚还有最后一本。你选小熊这本，还是小车这本？讲完就关灯。"
- Prevention: special time before bedtime and a visual bedtime routine.
- If it fails: reduce words, repeat one calm sentence; check sleep debt, fear, illness, or separation needs.

### Food throwing

- Quick help: stay calm, say the rule once, remove food if throwing continues.
- Script: "食物是吃的，不是扔的。你还想吃就放桌上；继续扔，我就知道你吃饱了。"
- Prevention: smaller portions, end meal when full, involve child in cleanup only if calm.
- If it fails: check hunger/satiety, texture, choking fear, growth, and caregiver reactions.

### Hitting or biting

- Quick help: block harm first.
- Script: "我不会让你打人。你很生气，可以跺脚，不能打。"
- Prevention: practice replacement actions when calm; reduce known triggers.
- If it fails: persistent or injurious aggression moves to yellow triage.

### Tantrum / emotional meltdown

- Quick help: fewer words, lower body, calm presence.
- Script: "你真的很想要。现在不能买。我在这里陪你哭一会儿。"
- Prevention: preview transitions, snack/rest check, limited choices.
- If it fails: track time, trigger, sleep, hunger, sensory overload, and frequency.

### Separation anxiety

- Quick help: short goodbye, predictable return phrase.
- Script: "我抱你一下，然后我会走。午睡后我来接你。"
- Prevention: goodbye ritual, transition object, reunion routine.
- If it fails: extreme or persistent impairment moves to yellow triage.

### Toileting resistance

- Quick help: lower pressure and check readiness.
- Script: "身体准备好了会告诉我们。今天先坐一分钟，不出来也没关系。"
- Prevention: routine sit times, easy clothing, no shame.
- If it fails: pain, constipation, blood, or frequent accidents after age 5 need professional input.

### Screen transition

- Quick help: preview ending and give an action after screen.
- Script: "还有两分钟。结束后你选搭积木还是洗澡玩水。"
- Prevention: visual timer, same ending routine, adult consistency.
- If it fails: reduce daily friction by changing access rules, not arguing at every ending.

### Grandparent disagreement

- Quick help: choose one shared bottom line, not a full philosophy debate.
- Script: "我们想先统一一件事：睡前不再加糖和新动画。其他做法我们慢慢磨合。"
- Prevention: weekly one-card summary and respectful appreciation.
- If it fails: separate safety boundaries from style preferences.
