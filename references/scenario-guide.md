# 🛠 积极育儿场景实操指南

> 基于积极育儿核心理念，针对日常高频冲突场景的完整操作手册。

---

## 一、睡前场景

### 1.1 睡前流程（提前设计）

跟孩子一起画一个睡前流程图，贴在墙上。顺序建议如下：

```
换尿不湿 → 刷牙 → 讲故事（约定本数）→ 特殊时光（聊天/拥抱）→ 关灯 → 睡觉
```

**关键点：**
- 换尿不湿放在讲故事之前！这样他后面就不能用这个借口拖延
- 故事数量提前约定，比如"今晚两本，你来选哪两本"
- 流程图让孩子参与画，他才有"这是我自己定的"的感觉
- 执行时不要说"该睡觉了"，说"惯例表上现在该做什么了？"

### 1.2 特殊时光（每天固定）

在讲故事环节加入"特殊时光"——15-20分钟的全身心陪伴。

**规则：**
- 时间固定，不是说"有空就陪"
- 放下手机，不做别的事
- 做什么由孩子决定（讲故事、聊天、玩小游戏都可以）
- 时间到了就说"今天的特别时光结束了，明天同一时间我们继续"

**为什么有效：** 孩子知道"每天都有一段确定的时间爸爸妈妈完完全全是我的"，就不需要在其他时间反复索取关注。

### 1.3 有限选择（随时可用）

把"不行"变成"你选A还是B"，A和B都是你能接受的。

#### 常用话术清单

| 孩子说 | 不要说 | 要说 |
|--------|--------|------|
| "我还要听故事" | "不行，太晚了" | "今天的故事时间到了。你想让爸爸握左手还是右手陪你睡？" |
| "我要换尿不湿"（干的） | "你明明没尿" | "你摸摸看是不是干干的？你是想自己摸还是让爸爸摸？" |
| "我要去客厅" | "不能去" | "现在该睡觉了。你是想闭着眼听爸爸哼歌，还是听爸爸轻轻拍你的背？" |
| "我不要睡觉" | "你必须睡" | "睡觉时间到了。你是想让爸爸拍拍背还是摸摸头？" |
| 两个都不选 | 慌了开始劝说 | 平静说"那爸爸帮你选"，然后执行其中一个 |

**四个使用要点：**
1. 两个选项都必须你能接受
2. 他都不选时：平静帮选，不慌不谈
3. 选择要简短，不要解释太多
4. 日常各种场景都用（吃饭、出门、洗澡），让他习惯做选择

### 1.4 睡前讲故事喋喋不休 — 管教前三问实战

**场景：** 讲完两个故事了，孩子还在"再讲一个嘛再讲一个嘛"，你开始烦躁了。

**第1问：我是在控制他还是引导他？**
- ❌ 控制："闭嘴！说好了两个就两个！"→ 他学到"声音大的一方赢"
- ❌ 控制的另一种："你再这样爸爸就不喜欢你了"→ 他学到"爱是有条件的"
- ✅ 引导：他想跟你多待一会儿，用别的方式满足这个需求
- 实际话术："爸爸知道你还想跟我在一起，对不对？来，我们关了灯聊三分钟今天最开心的事，然后一起闭眼睛。"

**第2问：五年后他会因为我今天的反应学到什么？**
- 吼他"别吵了睡觉" → 五年后他跟同学冲突时也会大吼对方"你闭嘴！"
- 说"我知道你还想听，但约定了两个。来，握着爸爸的手，一起数到三十" → 五年后他知道"我可以失望，但规则就是规则"，这是自我调节能力

**第3问：我能不能让他参与解决问题？**
- ❌ 单方面命令："不许再讲了！睡觉！"
- ✅ 让他参与："你觉得我们该怎么办？你已经听了两个故事了，但你还想跟爸爸待一会儿。你有什么好办法吗？"
  - 他可能说"那我们聊天" → ✅ 好，关灯聊两分钟
  - 他可能说"那你抱着我" → ✅ 好，抱一下然后躺好
  - 他可能说"再讲一个嘛" → "故事时间结束了，但我们还有三分钟聊天时间，你想聊什么？"

**三问的本质：**
- 控制还是引导？ → 从"对付他"转向"理解他"
- 五年后学到什么？ → 从"当下解决"转向"长期影响"
- 能让他参与吗？ → 从"我命令你"转向"我们一起想办法"

### 1.5 孩子哭了怎么办（三步法）

**第一步：共情（看见感受）**

用语言说出他的感受，不要否定，不要讲道理。

- ✅ "你真的很想换一个新的对不对？被拒绝了好难过。"
- ✅ "我知道你还不想睡觉。"
- ✅ "你是不是还想跟爸爸妈妈待在一起？"
- ❌ "别哭了，没什么好哭的。"
- ❌ "你已经很大了。"
- ❌ "你明明没尿。"

**第二步：帮他平复（身体介入）**

他的理性脑关闭了，讲道理没用。用身体帮助他缓和：

1. **轻拍背或握手** — 催产素帮助他从应激状态缓和下来
2. **降低声音和语速** — 用比平时更低更慢的声音说"爸爸在"
3. **呼吸示范** — 你自己慢慢深呼吸发出声音，他可能不自觉跟上来
4. **等哭的力度变小** — 理性脑开始恢复了，再介入给选择

**第三步：坚定（守住界限）**

平复之后，温柔但明确地重复规则：

- "尿不湿是干的，不需要换。爸爸在这里陪你。"
- "今天的故事讲完了，明天我们继续。"

**顺序记住：先共情 → 再平复 → 最后坚定。不能反过来。**

### 1.6 半夜哭闹处理

**先判断：** 摸一下尿不湿。湿的→换。干的→下面流程。

**处理原则：少刺激，刚好够**
1. 轻声说"爸爸在"
2. 安静拍拍他
3. 不多说话，不开灯

**绝对不要：**
- ❌ 从拍升级到抱
- ❌ 从抱升级到讲故事
- ❌ 半夜跟他互动太多

否则他学到的是"半夜哭 = 能跟爸爸玩"，越来越频繁。

**如果一周出现三四次以上：** 说明白天的连接不够，需要强化特殊时光。

### 1.7 他反复试探边界怎么办

**心态转换：** 他不是在跟你作对，是在"摇栏杆"确认规则是否可靠。就像你走一座晃动的桥，你会抓住栏杆摇一摇看牢不牢。

**执行原则：**
- **一致性最关键** — 今天坚持明天妥协，他学到的是"闹够久就能打破规则"
- **重复同一句话** — 不要换着花样说，就重复同一句温柔而坚定的话
- **坚持三到五天** — 他发现规则是稳固的，试探行为会明显减少

**你力不从心的时候：** 不要硬撑。你可以说："爸爸现在有点累了，需要休息一分钟。"然后闭上眼睛深呼吸几次。这是在示范"大人也会有情绪，也可以用健康的方式处理"。

## 二、吃饭场景 — 孩子扔食物

### 2.1 场景描述

孩子吃一半开始把食物扔到地上，弄得满地都是。你很生气，因为视觉冲击强，加上你还要收拾。

### 2.2 解码：他在争夺权力

你的感受：愤怒 → 他在寻求权力。

你越生气他越来劲，因为你的愤怒反应告诉他"你成功影响了爸爸"——这对权力争夺中的孩子来说，就是一种"赢"。

### 2.3 扔食物的三个可能原因

1. **吃饱了无聊了** — 还坐在那没事干，扔着玩
2. **想引起你的反应** — 你越生气他越起劲
3. **试探边界** — "我这样做会怎样？"

不管哪种，核心都是：**不要让他从你的反应中获得"赢"的感觉。**

### 2.4 三步处理法

**第1步：稳住自己（最重要）**

你的愤怒是他的"燃料"。你越怒，他越觉得自己有力量。深呼吸，让自己从"他在挑战我"切换到"他在用错误的方式表达什么"。

**第2步：温和而坚定地说一次**

蹲下来跟他平视（不要居高临下），平静地说：

> "食物是吃的，不是扔的。如果你继续扔，说明你吃饱了，爸爸就把碗收走。"

要点：
- 语气平静，不带怒气（你一怒他就"赢"了）
- 只说一次，不重复（重复 = 讨价还价 = 权力争夺）
- 把后果说清楚，然后等他的选择

**第3步：他继续扔？——行动，不要再说话**

这是最关键的一步。说了后果就必须执行，否则他学到"你说的话不算数"。

他如果继续扔，你平静地：
1. 把碗收走
2. 说一句："看来你吃饱了。那我们结束吃饭。"
3. 然后抱他下餐椅

**绝对不要：**
- ❌ 再讲道理"你看你把地上弄得好脏"（他不在乎，他在乎的是他成功激起了你的反应）
- ❌ 威胁"你再扔我就打你了"（威胁 = 新的权力争夺）
- ❌ 妥协"那你别扔了，再吃两口"（他学到"扔了还能继续吃"）
- ❌ 暴怒（他学到"闹得够大就能让爸爸失控"，这也是一种赢）

**关键心法：平静地执行后果 = 你没有在跟他打仗，你只是在执行一个规则。**

### 2.5 地上的食物怎么处理？

- 你先收拾，等他情绪平静后（不是当场），跟他说"刚才的食物弄到地上了，你来帮爸爸一起擦干净"——让他参与但不是惩罚
- 如果他大一点（3岁以上），可以在饭后平静地说"弄到地上的食物，我们一起收拾"——一起做，不是让他一个人做

**收拾是自然后果的一部分，但不是惩罚。** ❌ 不要说"你扔的你自己捡，看你下次还敢不敢"——这又是惩罚了。

### 2.6 他下餐椅后哭闹怎么办？

用你的情绪解码器判断：
- **烦躁** → 他在寻求关注 → "爸爸知道你还想吃饭/不想下去，但吃饭的时候不扔食物。等你想好好吃了我们再吃。"
- **愤怒** → 他还在争夺权力 → 不要接招，平静地重复"等你准备好了，可以好好吃饭了，我们再试试"

他哭就让他哭一会，你在旁边陪着但不妥协。**陪伴但不让步 = 温和而坚定。**

### 2.7 提前预防

最好的处理方式是"不让它发生"：
- 他吃一半开始玩/分心 → 可能已经吃饱了，别硬塞
- 吃饭前让他有点参与感："今天用蓝碗还是绿碗？""你来帮爸爸把筷子摆好"
- 如果他连续几天都扔 → 考虑是不是饭量太大吃不完，或者坐太久无聊了

### 2.8 一句话原则

**说一次，平静执行，不讲道理不发脾气。让他学到"扔食物 = 吃饭结束"，而不是"扔食物 = 爸爸失控"。**
