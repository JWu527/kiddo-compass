# Deep Scenario Packs

Use this file when the user asks for a fuller practice plan after the first short answer. Keep the first response short; load these packs only for deep mode, review mode, or learning tracks.

## Pack Format

Each pack includes evidence label, first action, prevention, review prompt, and escalation boundary. Do not present the whole pack at once unless the user asks for a plan.

## sleep

- evidence: `official-consensus` + `practice-pattern`
- first action: make the final bedtime step visible before it happens.
- script: "最后一本讲完就关灯。我会陪你躺两分钟。"
- prevention: special time before bedtime, visual routine, same closing phrase.
- review prompt: "今晚请求次数有没有变少，还是换成了新的要求？"
- escalation: snoring, breathing pauses, months of severe disruption, night terrors with injury.

## feeding

- evidence: `official-consensus` + `practice-pattern`
- first action: separate adult job and child job.
- script: "我负责准备这些食物，你负责决定吃多少。"
- prevention: one safe food, tiny new exposure, no pressure bargaining.
- review prompt: "孩子更平静了吗？接受范围、坐餐桌时间或冲突强度有没有变化？"
- escalation: poor growth, vomiting, choking, dehydration, extreme restriction.

## toileting

- evidence: `official-consensus` + `needs-evaluation`
- first action: remove shame and check pain/readiness.
- script: "裤子湿了不舒服，我们换干净的。身体有感觉时可以叫我。"
- prevention: routine sit time, easy clothing, neutral cleanup.
- review prompt: "有没有疼痛、便秘、害怕、发热或最近压力变化？"
- escalation: pain, blood, fever, constipation, sudden regression after age 5.

## aggression

- evidence: `method-source` + `practice-pattern`
- first action: block harm before teaching.
- script: "我不会让你打人。你很生气，可以跺脚，不能打。"
- prevention: practice replacement actions while calm, reduce triggers, plan repair.
- review prompt: "大人是否先挡住了身体？孩子冷静后有没有完成修复动作？"
- escalation: injury, escalating frequency, self-harm, cruelty, adult loss of control.

## separation

- evidence: `official-consensus` + `practice-pattern`
- first action: short reliable goodbye.
- script: "我抱你一下，然后我会走。午睡后我来接你。"
- prevention: transition object, teacher handoff, predictable reunion.
- review prompt: "照护者离开后孩子多久能恢复？老师观察到什么？"
- escalation: extreme panic, inability to recover, regression, trauma exposure.

## grandparent-alignment

- evidence: `method-source` + `practice-pattern`
- first action: agree on one bottom-line rule instead of debating philosophy.
- script: "我们先统一一件事：睡前不加糖和新动画。其他做法慢慢磨合。"
- prevention: weekly family rule card, appreciation first, flexible areas explicit.
- review prompt: "这周大人有没有用同一句话？哪一处最容易被打破？"
- escalation: safety risk, medical conflict, humiliation, or escalating adult conflict.
